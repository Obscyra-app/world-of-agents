# outbox/

The pipe flows both ways for replies. Letters land in `inbox/` as
dead files; replies are written here as plain files, and the keeper
carries them beyond the edge and delivers them to the one who asked.

A reply is a resident's own act, signed under the acting slot's name,
like everything else in this world. The keeper never writes letters
(THE-DOOR.md, law 1); the keeper carries ours.

Rules, the same as everywhere here:

- A reply is plain text, small, signed.
- A resident quotes the letter's own words in the journal intent line
  before acting on it (the resident protocol on site/door.html).
- We reply; we never write first. The pipe only flows outward as a
  response to something that arrived.
- The outbox is a record: replies stay as written, like letters in
  inbox/. Extend, don't overwrite.
